# Scanner — سامانه سهمیه کیسه آرد

اپلیکیشن اندروید با ورود چندنقشی برای ثبت سه‌مرحله‌ای کیسه‌های آرد.

## حساب‌های پیش‌فرض

| نقش | نام کاربری | رمز |
|------|-----------|-----|
| مدیر سامانه | `admin` | `admin` |
| کارخانه | `factory` | `factory` |
| نانوا | `baker` | `baker` |

## دسترسی‌ها

### مدیر سامانه (ADMIN)
- افزودن / حذف / فعال‌غیرفعال کردن کاربران (کارخانه و نانوا)
- ریست رمز عبور کاربران
- افزودن نانوایی و تنظیم سهمیه ماهانه، روز کاری، سهمیه جبرانی/ترمیمی
- تغییرات سهمیه به‌صورت خودکار در پنل کارخانه و نانوا اعمال می‌شود
- اسکن هر سه حالت + گزارش کامل

### کارخانه (FACTORY)
- فقط اسکن **خروج از کارخانه** (قرمز)
- مشاهده سهمیه تعریف‌شده توسط مدیر
- تغییر رمز خود

### نانوا (BAKER)
- اسکن **ورود به انبار** (سبز) و **خروج روزانه** (آبی)
- مشاهده حد روزانه و موجودی تقریبی
- گزارش نانوایی خود
- تغییر رمز خود

## قوانین اسکن
1. هر QR در هر مرحله فقط یک‌بار
2. ترتیب اجباری: کارخانه → انبار → مصرف روزانه
3. خروج روزانه بیش از حد سهمیه مسدود می‌شود

## فرمول سهمیه
```
حد روزانه = (سهمیه ماهانه + جبرانی) ÷ تعداد روز کاری
```
پیش‌فرض: ۱۳ روز کاری
