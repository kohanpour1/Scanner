# سامانه سهمیه آرد — Scanner

اپلیکیشن اندروید تجاری برای ثبت سه‌مرحله‌ای کیسه‌های آرد (۴۰ کیلو) با نقش‌های مدیر / کارخانه / نانوا.

## قابلیت‌ها
- **اسکن همه بارکدها**: QR, Code128, Code39, EAN, UPC, DataMatrix, PDF417, Aztec و ...
- **سهمیه به کیسه**: حد روزانه و سهمیه کل بر حسب کیسه + معادل کیلوگرم (×۴۰)
- **کسر از سهمیه کلی** با هر خروج روزانه
- **توزیع خودکار روزهای مصرف‌نشده** و بانک کسری برای دقت ۴۰کیلو (مثال ۵.۶۷ → فقط ۵ کیسه تا بانک پر شود)
- **خروجی Excel (CSV) و PDF** برای همه نقش‌ها؛ مدیر گزارش همه را می‌بیند
- **تنظیم هاست/سرور** در همه پنل‌ها برای آنلاین شدن بعدی (همگام‌سازی بین گوشی‌ها)
- **دکمه خروج** از حساب
- UI شیفت‌شده به پایین تا زیر نوار وضعیت گوشی نرود
- آفلاین‌اول + لوگو و لانچر
