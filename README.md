# سهمیه آرد — Scanner

اپلیکیشن اندروید تجاری برای ثبت سه‌مرحله‌ای کیسه آرد (۴۰ کیلو) با نقش‌های مدیر / کارخانه / نانوا.

## حساب‌ها
| نقش | کاربر | رمز |
|------|--------|------|
| مدیر | admin | admin |
| کارخانه | factory | factory |
| نانوا | baker | baker |

## سهمیه شناور و باقی‌مانده کسری
- پایه روزانه = (سهمیه ماه + جبرانی) ÷ روز کاری
- اگر روزی بدون مرخصی سهمیه مصرف نشود، باقی‌مانده بین روزهای بعد تقسیم می‌شود
- کیسه‌ها فقط صحیح اسکن می‌شوند؛ بانک کسری (مثلاً ۰٫۶۷) ذخیره می‌شود
- وقتی با گرفتن یک کیسهٔ اضافه (مثلاً ۶ به‌جای ۵٫۶۷) محاسبات به‌هم می‌ریزد، سقف آن روز به تعداد صحیح پایین‌تر محدود می‌شود

## مرخصی
مدیر می‌تواند برای هر نانوایی «مرخصی امروز» ثبت کند؛ آن روز از مخرج روز کاری خارج و سهمیه بین بقیه روزها پخش می‌شود.
